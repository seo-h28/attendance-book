# 복지관 출석부 웹앱

어르신 프로그램(노래교실 등) 출석을 **태블릿에서 이름 초성을 눌러 바로 체크**하는 웹앱입니다.
종이 명단에 손으로 적느라 줄이 길어지던 문제를 줄이는 것이 목표입니다.

- 봉사자: 어르신 이름의 초성(예: 김미자 → `ㄱㅁㅈ`)을 누르고 이름 카드를 터치하면 출석이 기록됩니다.
- 동명이인: 이름 카드에 **전화번호 뒷자리**가 함께 보입니다. `전화 뒷자리` 탭에서 번호로 찾을 수도 있습니다.
- 담당자: 신청 명단 엑셀을 불러오고, 월별·분기별 **출석부 엑셀**을 받아 인쇄·보관합니다.

---

## 1. 개인정보 처리 구조 (개발자는 개인정보를 보지 않음)

| 위치 | 저장되는 것 | 누가 다루나 |
|---|---|---|
| 웹앱 코드 (인터넷 주소) | 화면과 기능 코드만. **명단·출석 데이터 없음** | 개발자 |
| 각 태블릿의 브라우저 저장소 | 이름, 전화번호 **뒷 4자리**, 수업 이름, 출석 시각 | 기기 안에만 저장 |
| 담당자 PC / 복지관 내부 저장소 | 원본 신청 명단, 내려받은 출석부 엑셀 | 담당자 |

- 앱은 데이터를 **외부 서버로 보내지 않습니다.** 서버가 없습니다.
- 명단 엑셀에 생년월일·금액·결제 칸이 있어도 **읽지 않습니다.** 전화번호도 뒷 4자리만 저장합니다.
- 관리 화면은 숫자 4자리 비밀번호로 잠겨 있습니다. 보안 장치라기보다 봉사자분이 실수로 명단을 바꾸는 일을 막는 용도입니다.
- 명단을 불러오고 출석부를 내려받는 일은 **담당자만** 합니다. 개발자는 설치를 돕더라도 명단 파일은 열지 않습니다.

## 2. 체험 모드 (가상 데이터)

주소 끝에 `?demo`를 붙이면(예: `http://localhost:8123/?demo`) **가상 데이터가 미리 들어간 체험 모드**로 열립니다. 명단이 없을 때 첫 화면의 **[가상 데이터로 체험해 보기]** 버튼으로도 들어갈 수 있습니다.

- 수업 5개(노래교실 114명, 줌바댄스, 파워로빅, 서예교실, 스마트폰교실)와 가상 인물이 들어 있습니다. 노래교실에는 동명이인 `김미지 1311 / 1322`도 있습니다.
- 지난달 1일부터 오늘까지 출석 기록이 채워져 있습니다. 오늘 수업은 절반쯤 출석한 상태이고, 수업마다 이번 달 휴강일이 하루씩 있습니다.
- 관리 비밀번호는 **0000**이며, 화면 위 노란 줄에 항상 표시됩니다.
- 체험 데이터는 **실제 데이터와 따로 저장**됩니다. 마음껏 눌러도 실제 명단과 기록에는 영향이 없습니다.
  - 체험 모드에서 저장한 엑셀은 파일 이름이 `체험_`으로 시작합니다. 실제 출석부에 합치려고 하면 거절됩니다.
- **[가상 데이터 새로 만들기]**는 처음 상태로 되돌리고, **[체험 끝내기]**는 실제 화면으로 돌아갑니다.
- 봉사자 교육용으로 써도 좋습니다. 실제 태블릿에서 `?demo` 주소로 연습한 뒤 그냥 원래 주소로 쓰면 됩니다.

## 3. 담당자 사용법

### 처음 한 번
1. 태블릿 크롬에서 앱 주소를 엽니다 → 메뉴(⋮) → **홈 화면에 추가**. 이후에는 앱처럼 아이콘으로 엽니다.
2. 오른쪽 위 **[관리]** → 관리 비밀번호 4자리를 정합니다.
3. **[설정]** 탭 → 기기 이름(예: `태블릿1`)을 적습니다.
4. **[명단 · 수업]** 탭 → **[명단 엑셀 불러오기]** → 신청 명단 파일을 고릅니다.
   - 첫 줄 근처에 `이름`, `전화번호`, `프로그램명` 제목 칸이 있으면 수업별로 자동으로 나뉩니다.
   - `프로그램명` 칸이 없으면 **시트 이름**을 수업 이름으로 씁니다(예: `노래교실(주1회)` → `노래교실`).
   - 이름 뒤에 뒷자리를 붙여 둔 `김미지1311` 형식도 알아서 나눕니다.
   - 양식이 헷갈리면 **[빈 명단 양식 받기]**로 받은 파일에 붙여 넣으세요.
5. 수업마다 **색깔·요일·시간·강사**를 정합니다. 색깔은 처음 불러올 때 수업마다 다르게 자동으로 정해지며(파랑·주황·보라 …), 수업 선택 화면과 출석 체크 화면 위쪽이 그 색으로 표시되어 지금 어느 수업인지 헷갈리지 않습니다. 요일을 정해야 그날 수업이 자동으로 먼저 뜨고 출석부에 날짜 칸이 생깁니다.
6. 태블릿 2대 모두 4번까지 똑같이 합니다.

### 수업 날
1. 앱을 열면 오늘 요일의 수업이 위에 나옵니다 → 수업을 누릅니다.
2. 봉사자가 이름을 듣고 초성을 누르고 → 이름 카드를 누르면 끝입니다. 화면 위에 `○○○ 님 출석!`이 뜹니다.
   - 잘못 눌렀으면 바로 뜨는 **[취소]**, 또는 초록색 카드를 다시 눌러 취소합니다.
   - 명단에 없는 분은 **[+ 명단에 없는 분 출석]**으로 기록합니다. 출석부에 `*` 표시가 붙습니다.
3. 출석 체크 화면에서는 화면이 꺼지지 않습니다.

### 달력
수업 선택 화면이나 출석 체크 화면 위쪽의 **[달력]**을 누르면 한 달 달력이 나옵니다. 비밀번호 없이 열 수 있고, 이름 없이 인원수만 보여 줍니다.
- 날짜 칸마다 그날 있는 수업이 **수업 색깔**로 표시됩니다. 지난 날짜에는 `출석 인원/전체 인원`(예: `70/112`)이 함께 나옵니다.
- 휴강일은 회색 줄과 `휴강`으로 표시됩니다.
- 날짜를 누르면 오른쪽(세로 화면에서는 아래쪽)에 수업별 시간, 강사, 출석 인원, 출석률 막대가 나옵니다. 오늘 날짜에서는 **[출석 받기]**로 바로 출석 화면에 들어갈 수 있습니다.
- 수업 선택 화면의 오늘 수업 카드에도 `오늘 37 / 112명 출석` 또는 `오늘 휴강`이 표시됩니다.
- 이 숫자는 **그 태블릿에 쌓인 기록 기준**입니다. 태블릿 2대 기록을 합치기 전에는 각자 받은 인원만 보입니다.

### 매달 / 분기마다
- **출석부 받기**: [관리] → [출석부 저장 · 합치기] → 수업, 시작 달, 기간(1개월/3개월) 선택 → **[출석부 엑셀 저장]**.
  기록이 없어도 명단과 날짜가 채워진 **빈 출석부**가 만들어져 인쇄할 수 있습니다.
- **태블릿 2대 기록 합치기**: 태블릿마다 기록이 따로 쌓입니다.
  1. 각 태블릿에서 [출석부 엑셀 저장]을 누릅니다(다운로드 폴더에 저장).
  2. 두 파일을 담당자 PC 또는 복지관 내부 저장소로 옮깁니다.
  3. PC에서 앱을 열고 **[다른 기기 파일 합치기]**로 두 파일을 차례로 불러옵니다.
  4. 다시 [출석부 엑셀 저장]을 누르면 두 기기 기록이 합쳐진 출석부가 됩니다.
  - 출석부 엑셀 안에는 숨김 시트(`_data`)로 전체 기록이 함께 들어가 있어서, **이 파일이 곧 백업**입니다. 지우지 마세요.
- **명단이 바뀔 때**(새 분기, 추가 접수): 새 명단 파일을 다시 불러오면 됩니다. 지난 출석 기록은 그대로 남고, 빠진 분은 출석부에 `(취소)`로 표시됩니다.
- **휴강일**: [명단 · 수업]에서 수업별로 날짜를 추가하면 출석부에 회색 `휴강`으로 표시됩니다.
- **지난 기록 고치기**: [출석 현황] 탭에서 칸을 누르면 출석/결석이 바뀝니다.

### 주의
- 태블릿의 **브라우저 데이터 삭제**나 **기기 초기화**를 하면 그 태블릿의 기록이 사라집니다. 2주에 한 번은 출석부 엑셀을 저장해 두세요(관리 화면에 마지막 저장일이 표시됩니다).
- 관리 비밀번호를 잊으면 그 기기에서는 [모든 기록 지우기] 말고는 방법이 없습니다. 비밀번호는 담당자 수첩 등에 따로 적어 두세요.
- `.xls`(옛 엑셀 형식)는 못 읽습니다. 엑셀에서 **다른 이름으로 저장 → Excel 통합 문서(.xlsx)**로 바꿔 주세요.

## 4. 설치 · 배포 (개발자용)

빌드 과정과 외부 라이브러리가 없는 정적 파일입니다. 엑셀 읽기·쓰기까지 직접 구현했기 때문에 CDN이나 패키지 버전이 바뀌어도 깨지지 않습니다.

```
index.html            화면 틀
css/style.css         디자인 (큰 글씨, 가로/세로 태블릿 대응)
js/app.js             화면과 동작
js/store.js           기기 안 저장, 기록 합치기
js/hangul.js          초성 검색
js/roster.js          명단 엑셀 해석, 백업 시트
js/book.js            출석부 엑셀 만들기
js/demo.js            체험 모드용 가상 데이터
js/xlsx.js            .xlsx 읽기/쓰기 (외부 라이브러리 없음)
sw.js                 와이파이 없이도 열리게 하는 오프라인 캐시
tools/make_sample.py  테스트용 가짜 명단 생성
sample/샘플_명단.xlsx  가짜 이름으로 만든 테스트 명단 (182명)
```

**내 PC에서 실행**

```bash
python -m http.server 8123
```

→ 브라우저에서 `http://localhost:8123` 접속. (파일을 더블클릭해서 열면 동작하지 않습니다.)

### 배포: GitHub Pages (무료, 서버 관리 없음)

태블릿에서 쓰려면 HTTPS 주소가 필요합니다. 올리는 것은 **코드뿐**이고, 명단과 출석 기록은 지금처럼 각 태블릿 안에만 남습니다.

1. **계정**: 복지관 이메일로 GitHub 계정을 만들고 **2단계 인증**을 켭니다(권장). 개발자는 이 저장소의 공동 작업자로 초대받습니다.
   개인 계정에 올릴 수도 있지만, 그러면 개발자 계정이 해킹됐을 때 코드가 바뀔 위험이 개발자 쪽에 남습니다(아래 '보안 구조' 참고).
2. 저장소를 **Public**으로 만듭니다(무료 Pages 조건). 코드만 공개되고 데이터는 없으므로 괜찮습니다.
3. 이 폴더를 올립니다. `.gitignore` 덕분에 `*.xlsx` 같은 실제 명단 파일은 올라가지 않습니다. 가짜 이름으로 만든 `sample/샘플_명단.xlsx`만 예외입니다.
   ```bash
   git remote add origin https://github.com/<계정>/<저장소>.git
   ```
   ```bash
   git push -u origin main
   ```
4. 저장소 **Settings → Pages → Branch `main` / `/ (root)` → Save**, 그리고 **Enforce HTTPS**를 켭니다.
5. 몇 분 뒤 `https://<계정>.github.io/<저장소>/`를 태블릿 크롬에서 열고 **홈 화면에 추가**합니다.
6. 저장소 **Settings → Branches**에서 `main`에 보호 규칙(강제 푸시·삭제 금지)을 겁니다.

### 보안 구조 — 개발자가 데이터에 접근하지 않는 이유

- **서버가 없습니다.** GitHub Pages는 앱 파일(HTML·JS)만 내려 주고, 명단·출석 기록은 받지도 보관하지도 않습니다. 개발자가 접속해서 볼 수 있는 데이터 저장소가 처음부터 없습니다.
- **외부 전송이 막혀 있습니다.** `index.html`의 보안 정책(Content-Security-Policy)이 `connect-src 'none'`, `form-action 'none'`으로 앱의 인터넷 전송을 차단합니다. 외부 스크립트·글꼴·광고·분석 도구도 하나도 쓰지 않습니다.
- **남는 위험은 '코드 변경' 하나입니다.** 저장소 계정이 해킹되어 악성 코드가 올라가면 태블릿의 데이터를 빼낼 수 있습니다. 그래서 다음을 지킵니다.
  - 저장소는 복지관 계정이 소유하고, 2단계 인증을 켭니다.
  - 개발자 계정에도 2단계 인증을 켭니다. 수정이 필요할 때만 담당자 요청을 받아 고칩니다.
  - 모든 변경은 GitHub 기록(커밋 내역)에 남아서 누가 언제 무엇을 바꿨는지 확인할 수 있습니다.
- **태블릿 쪽 관리** (담당자):
  - 태블릿에 화면 잠금(비밀번호/패턴)을 겁니다.
  - 출석용 태블릿에는 개인 구글 계정이나 카톡 로그인을 하지 않습니다.
  - 분실하거나 폐기할 때는 [관리] → [설정] → [모든 기록 지우기] 후 공장 초기화합니다.
- **보관 기간**: [설정] → [오래된 기록 정리]로 1년 지난 출석 기록을 지울 수 있습니다. 복지관 개인정보 보관 기준에 맞춰 분기나 연 1회 정리하세요.
- **저장 용량**: 기기당 브라우저 저장 한도(약 5MB) 안에서 출석 기록을 대략 2년 치 보관할 수 있습니다. 1년마다 정리하면 문제없습니다.

### 문제가 생겼을 때 (개발자 접근 없이 해결)

1. 담당자가 [관리] → [설정] → **[문제가 생겼을 때] → [내용 복사]**를 눌러 진단 정보를 보냅니다. 앱 버전, 인원수, 기록 건수, 브라우저 정보만 들어 있고 이름·번호는 없습니다.
2. 화면 사진을 함께 받습니다. 이름이 보이면 가려 달라고 요청합니다.
3. 개발자는 **체험 모드(`?demo`)에서 똑같이 재현**해 고칩니다. 실제 명단 파일이나 출석부 엑셀은 받지 않습니다.

### 코드를 고쳐 다시 배포할 때

1. `js/app.js`의 `APP_VERSION`과 `sw.js`의 `VERSION`을 같은 값으로 올립니다(예: `1.0.0` → `1.0.1`).
2. 커밋하고 푸시하면 GitHub Pages가 1~2분 안에 반영합니다.
